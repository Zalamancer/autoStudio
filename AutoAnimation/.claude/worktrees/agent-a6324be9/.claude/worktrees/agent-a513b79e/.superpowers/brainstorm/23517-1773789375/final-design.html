Design Summary

  • Presets tab (default) — Search bar → Quick Moves chips → Genre horizontal scroll → Cinema list with category filter
  • Camera tab — Body select → Lens select → Aperture/Focus/ISO sliders → 7 optical toggles
  • Virtual Camera toggle shared on both tabs
  • Footer: Properties button on both tabs
  • Colors: All #4a7eff accent, #2a2a2a surfaces, #3a3a3a hover
