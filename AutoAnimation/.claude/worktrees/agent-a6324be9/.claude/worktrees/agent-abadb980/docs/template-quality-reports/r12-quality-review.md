## Quality Principles (Derived)

### A template scores HIGH when it has:
1. **Clean execution** — smooth, polished motion. The word "clean" appears in almost every positive review.
2. **Immediate use case** — user can instantly say "I'd use this for X" (titles, transitions, highlights, subtitles, reveals)
3. **Appropriate speed** — fast enough for subtitles/captions, not too slow
4. **Versatility** — works across multiple content types, not just one niche
5. **Text IS the visual** — the animation enhances the text, text is not secondary to a scene/object

### A template scores LOW when it has:
1. **No use case** — "cool but what would I use it for?"
2. **Too slow** — can't be used as subtitles or captions
3. **Too much effect** — distracting, overwhelming, can't scale to multiple words
4. **Too niche** — only works for one very specific content type
5. **Bad motion** — choppy, ugly, or boring animation despite good concept
6. **Object simulation** — building a compass/elevator/scaffold instead of enhancing text

### The Use Case Test
Every template should pass: "I'd use this for ___" where the blank maps to one of:
- Titles / intros
- Transition words between sections
- Highlight / emphasis words
- Subtitles / captions
- Reveal / tension moments
- Numbers / stats
- Genre-specific content (at least 3+ genres)
