# Hooks

38 custom React hooks in `src/hooks/`:

- `useKeyboardShortcuts()` — Global keyboard shortcuts
- `useKeyframePlayback()` — Apply interpolated keyframes to stores
- `useKeyframeRecorder()` — Record keyframes from user interaction
- `useCanvasInteraction(params)` — Zoom, pan, orbit, touch gestures
- `useAutoSave(debounceMs?)` — Auto-save with fingerprint dirty detection
- `useDialoguePlayback()` — Multi-character dialogue sync
- `useMotionCapture(options)` — Webcam motion capture
- `useMotionTracking()` — 3D motion tracking
- `useRigEditorBridge()` — Bridge to rig editor
- `useSafeGLTF(url)` — GLTF loading with error handling
- `useSchemaRuntime()` — Runtime schema evaluation
- `useFrameVisibility(start, end)` — Frame range visibility
- `useViralityScore()` — Virality score calculation
- `useBackgroundRemoval()` — Background removal state
- `useSilencePreview(mode)` — Silence removal preview
- `useTapTempo()` — Tap tempo detection
- `useFocusTrap(ref, active)` — Modal focus trap
- `useIsMobile()` — Mobile device detection
- `useLongPress(callback, delay)` — Long press gesture
- And 20+ more
