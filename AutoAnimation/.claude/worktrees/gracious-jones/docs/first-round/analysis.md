# First Round Analysis — What Works vs What Doesn't

## Stats
- **114 liked** (14.3%) — 92 kinetic, 22 scene
- **685 disliked** (85.7%) — 235 kinetic, 449 scene

---

## What Gets Liked — The Pattern

### 1. TEXT MANIPULATION is king (not data cards)
The user likes templates that **do something interesting to the text itself** — how it appears, moves, distorts, reveals, and disappears. NOT templates that display data, information, or UI layouts.

**Liked**: glitch distortion, typewriter reveal, ink bleed, handwriting, liquid fill, hologram scan
**Disliked**: workout cards, recipe displays, weather dashboards, product cards, analytics charts

### 2. Strong visual identity / reference to a real medium
Every liked template evokes a **real-world medium or aesthetic** that people instantly recognize:
- **CRT/Terminal**: typewriter, matrix rain, code terminal, arcade, game over
- **Film/Cinema**: letterbox, trailer title, lens flare, viewfinder, dark reveal
- **Print/Paper**: newspaper, propaganda poster, street poster, torn layers, blueprint
- **Manga/Anime**: impact frame, SFX, screentone, webtoon caption
- **Handcraft**: chalk, pencil, ink, quill, crayon, highlighter, post-it, stamp
- **Digital/Cyber**: glitch, hologram, HUD, wireframe, binary, digital rain

**Disliked**: Generic effects with no clear reference (bounce, carousel, color shift, aurora wave)

### 3. The text reveal/animation is the star — not the background
Liked templates have **distinctive text entrance/exit mechanics**:
- Letter-by-letter typing (typewriter, code terminal, chalk)
- Glitch/decode (matrix, binary, pixelate, glitch slam)
- Physical (stamp, ink bleed, liquid fill, clay morph, paper cut)
- Sweep/wipe (minimal mask, reveal line, circle iris, hologram scan)
- Split/shatter (triangle shard, split line, cyber slice, torn layers)

**Disliked**: Templates where text just fades/slides in with a decorative background

### 4. Minimal text effects are liked when PRECISELY executed
The minimal category had the highest approval rate:
- Minimal Fade, Mask, Reveal Line, Rotate, Slide Up — ALL liked
- These succeed because the animation mechanic is crisp and purposeful
- Fashion Editorial, Duotone — liked for the same reason

### 5. Scene templates only survive when they're text-first
The 22 liked scenes are ALL text-centric:
- **Quote displays**: 5 different quote cards (all liked)
- **Text content**: definition, journal, chapter title, POV, hooks
- **Social text**: tweet card, social post (text with UI chrome)
- **Data that reads as text**: stock ticker, nutrition facts, tier list
- **NOT liked**: Any scene that's primarily data visualization, charts, progress bars, dashboards

### 6. Categories that completely failed
- **Data visualization** (all): charts, gauges, progress bars, dashboards
- **Info cards** (all): spec cards, review cards, profile cards, comparison cards
- **Lifestyle/utility** (all): trackers, planners, schedules, guides, timers
- **Cultural patterns** (all): Aboriginal, Celtic, Chinese, African art styles
- **Nature backgrounds** (all): weather, seasons, flowers, ocean, forest
- **Music visualizer**: equalizer, waveform, DJ — too abstract
- **Horror gore**: blood drip, spider, zombie — too niche
- **Spiritual/meditation**: chakra, mandala, zen — too niche

## Rules for Generation (motion_design_skill)

### DO Generate:
1. **Text manipulation effects** — how text appears, transforms, distorts, reveals
2. **Medium-inspired** — each template should reference a recognizable real-world medium (print, film, digital, handcraft, manga)
3. **Distinctive entrance mechanic** — letter-by-letter, decode, physical stamp, sweep, split, etc.
4. **Clean minimal variations** — precise single-mechanic animations (mask, line, rotate, clip)
5. **Scene layouts ONLY for text content** — quotes, definitions, hooks, social posts, tickers

### DON'T Generate:
1. ~~Data cards~~ — no spec cards, dashboards, trackers, charts, visualizations
2. ~~Info displays~~ — no product cards, profile cards, review cards, comparison cards
3. ~~Generic backgrounds~~ — no nature scenes, weather, seasons, abstract particles
4. ~~Cultural art patterns~~ — no ethnic/regional art style templates
5. ~~Niche themes~~ — no horror gore, meditation/spiritual, music visualizer
6. ~~Basic effects~~ — no simple bounce, fade, carousel, color shift without a reference medium
7. ~~Lifestyle utility~~ — no workout trackers, recipe cards, travel guides, schedules

### Template Quality Checklist:
- [ ] Does it reference a recognizable visual medium?
- [ ] Is the text reveal/animation the primary feature?
- [ ] Would this work applied to ANY user text, not just specific content?
- [ ] Is the entrance mechanic distinct from a simple fade/slide?
- [ ] If a scene: is it text-centric (quote, title, label)?

## Categories to Explore for Round 2

Based on what was liked, these directions have more potential:

### More Kinetic Text Effects
- More print/typography references (letterpress, risograph, screen print, embossing, foil stamp, wax seal)
- More digital/tech (data corruption, buffer overflow, packet loss, signal interference, barcode)
- More film references (VHS rewind, film leader countdown, intermission, title card styles by decade)
- More craft (origami fold, paper airplane, stamp collection, sticker peel, tape, thread/stitch)
- More editorial (magazine cut, fashion lookbook, pull quote, sidebar, footnote)
- More architectural (isometric, CAD trace, section cut, elevation drawing)

### More Minimal Variations
- More precise single-mechanic reveals (curtain, venetian blind, accordion, zipper)
- More geometric reveals (diamond, hexagon, spiral, maze path)
- More text transforms (perspective tilt, anamorphic squeeze, fisheye, barrel distort)

### More Text-Centric Scenes
- More quote/text display variations
- More social media formats (reddit, discord, slack, iMessage, signal)
- More editorial formats (pull quote, sidebar, marginalia, footnote, index)
- More "internet culture" text (captcha, 404 error, loading screen, terms of service)
